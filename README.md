# PULSE SPORT

Loja demonstrativa de artigos esportivos, criada com React e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## O que já está implementado

- Layout responsivo com identidade visual preta e verde-limão
- Hero de campanha, categorias e produtos
- Filtros por categoria e busca de produtos
- Sacola interativa com quantidades e subtotal
- Favoritos e formulário demonstrativo de newsletter

## Observações

Este é um protótipo de interface. O checkout, pagamentos, estoque, contas de cliente e envio de pedidos ainda não estão conectados a serviços reais. Os produtos e preços são exemplos e devem ser revisados antes de publicar a loja.

As fotografias são carregadas de URLs do Unsplash, então precisam de conexão com a internet para aparecer.
